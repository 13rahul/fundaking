# Fundaking query → URL map (money pages)

**Purpose:** One primary money URL per head intent. Blogs support; they are never the commercial target.

**Rules**
- One primary URL per head term.
- `/seo-consulting-pune/` = buy/engage consulting in Pune.
- `/hire-seo-consultant-pune` = evaluate/hire decision (bridge to engagement).
- Hub blogs are supporting link sources only.
