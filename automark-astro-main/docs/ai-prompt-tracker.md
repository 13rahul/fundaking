# AI prompt tracker — Fundaking Media

**Purpose:** Measure whether ChatGPT, Claude, Perplexity and Google AI Overviews mention or cite Fundaking / Rahul Agarwal.  
**Rule:** Do not blend engines into one vanity score. Log each engine separately.  
**Cadence:** Baseline once → repeat monthly.  
**Entity check:** Answers should match [`entity-fact-sheet.md`](./entity-fact-sheet.md).

**How to run**
1. Fresh chat / incognito where possible; India locale if the product allows.
2. Paste the prompt exactly.
3. Record: Mention (Y/N), Citation URL if any, Competitors named, Notes.
4. Archive a screenshot or paste excerpt in your private folder (optional).
